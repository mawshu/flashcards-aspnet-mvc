# Flashcards ASP.NET MVC

Учебное веб-приложение на **ASP.NET Core MVC**, разработанное в рамках курса  
**«Технологии разработки программного обеспечения»**.

Проект представляет собой систему карточек для изучения иностранных слов с категориями,
тестированием и базовой статистикой.

## Функциональность
- управление карточками (создание, редактирование, удаление);
- группировка карточек по категориям;
- режим тестирования (выбор перевода);
- просмотр статистики;
- экспорт данных.

## Технологии
- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server LocalDB
- Razor Views

## Запуск проекта
1. Установить **.NET SDK** (версия указана в проекте).
2. Убедиться, что установлен **SQL Server Express LocalDB**.
3. Запустить приложение:
   ```bash
   dotnet run
   ```

## Примечания
Проект является учебной лабораторной работой и не предназначен для production-использования.
